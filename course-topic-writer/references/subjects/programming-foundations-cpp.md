# Programming foundations (C++)

- _Keywords_: основы программирования, Programming Foundations, C++, программирование для геймдизайнеров.
- _Audience_: USM, Game Design students, beginners; aim slightly below average. Explain especially simply and step by step, without academic heaviness.
- _Prerequisites_: school-level computer use. Programming, compilation, data types and so on are new until covered.
- _Language and platform_: Russian, C++. Bilingual terms are mandatory: compiler messages and documentation are in English.
- _Repository and files_: `MSU-Courses/programming-foundations`, folders `NN_Name/readme.md`, code examples in `NN_Name/code/`, images in `_images/NN/`. Chapters so far: 01 Введение, 02 Как "думает" программа, 03 Данные и введение в C++, 04 Выражения и операции, 05 Структурное программирование, 06 Как выполняется программа. Ошибки и отладка. Chapters 2-6 follow the chapter 5 skeleton: Содержание, Вопросы для самопроверки, "О чём мы говорили в прошлой главе?", sections, Типичные ошибки, Резюме, footnotes; no "Результаты обучения".
- _Running project and story_: examples from game logic (an enemy attacks the player when they get close, and so on).
- _Special elements_: diagrams instead of ASCII art in code blocks. Every chapter with code gets a `code/` folder of `.cpp` files compiled with `g++ -Wall -Wextra`.
- _Tools_: students build and run programs only in the IDE and have not learned command-line compilation. Do not show compiler commands or command-line flags (`g++ ...`, `-Wall`, `-Werror`) in chapter text; describe compiler settings as IDE project settings (for Visual Studio: Warning Level, Treat Warnings as Errors). Compiler messages may be quoted as they appear in the IDE's message window. Visual Studio is the reference IDE for screenshots (images from `MicrosoftDocs/visualstudio-docs`, CC BY 4.0).
- _To clarify with the user_: quote style, whether there is an opening story.
