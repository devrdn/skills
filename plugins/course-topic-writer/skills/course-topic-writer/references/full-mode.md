# Полный режим

Читай этот файл, когда пишешь новую главу или большой раздел (треть главы и больше). Общие первые шаги из SKILL.md уже сделаны.

1. *Источники.* Запусти 1-3 субагента "Исследователь" параллельно по подтемам, затем "Сверщика" на общем файле `sources.md` (рабочий файл, автору не отдаётся). Утверждение без источника помечается в плане "нужен источник" и в текст как утверждение не попадает.
2. *План.* Покажи план и дождись согласия. В плане:
   - разделы по порядку, у каждого одна строка об идее и о переходе от предыдущего;
   - карта терминов: какие новые термины вводит каждый раздел (ни один термин не нужен раньше раздела, где он определён);
   - какие факты из `sources.md` использует каждый раздел;
   - рисунки: номер, подпись, что показывает, откуда взят;
   - элементы профиля (карточки сервисов, ссылки на hands-on и так далее);
   - открытые вопросы и все пометки "нужен источник".

   Если пользователь указал образцовую главу, возьми из неё скелет. Если пользователь недоступен, напиши, что план не согласован, и продолжай.
3. *Текст.* Пиши по плану, раздел за разделом: сначала рамка (заголовок, содержание, вопросы, ретроспектива), потом разделы, потом резюме и сноски. Если план оказался неверным, меняй план, а не порядок терминов.
4. *Код.* Если в главе есть код, собери папку по `references/code-folder.md`.
5. *Проверки.* Параллельно запусти субагентов "Рецензент", "Корректор структуры" и "Читатель". По каждому замечанию реши: исправить или отклонить с причиной. При конфликте: факты, порядок терминов, код и правила курса решает Рецензент; лишнее и недостающее для слабого студента решает Читатель.
6. *Редактор.* Запусти субагента "Редактор" на всём тексте и примени его правки. Это и есть вычитка полного режима.
7. *Иллюстрации* по `references/illustrations.md`, с учётом раздела C отчёта Читателя.
8. *Сдача.* Прогони скрипт: замечания о нумерации, ссылках на рисунки и сносках исправь обязательно. Отчёты проверяющих не вставляй; одной строкой напиши, что не удалось исправить, проверить или проиллюстрировать.

Если инструмента для субагентов нет, выполни каждую проверку сам отдельным проходом по файлу роли и скажи об этом.

## Субагенты

Субагент получает файл своей роли и перечисленные в нём файлы, а не пересказ разговора. Если установлен плагин `course-topic-writer`, Рецензента, Читателя и Редактора запускай агентами плагина (`subagent_type`: `course-topic-writer:reviewer`, `course-topic-writer:student-reader`, `course-topic-writer:editor`): у них уже есть задание и нет права правки, передай им только полные пути к файлам. С инструментом Agent укажи `model`; если модель недоступна, используется модель сессии. План, текст, код, иллюстрации и правки остаются в основной сессии: текст главы пишет только она.

| Роль | Файл | Модель |
| --- | --- | --- |
| Исследователь | `researcher.md` | `sonnet` |
| Сверщик | `verifier.md` | `haiku` |
| Рецензент | `reviewer.md` | `opus` |
| Корректор структуры | `structure-checker.md` | `haiku` |
| Читатель | `student-reader.md` | `sonnet` с веб-поиском |
| Редактор | `editor.md` | `sonnet` |
