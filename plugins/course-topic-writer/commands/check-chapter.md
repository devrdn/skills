Проверь главу курса по скиллу `course-topic-writer` в режиме "Проверка". Файл главы не меняй.

Глава: $ARGUMENTS

Если путь не указан, найди в текущем репозитории файлы глав (`NN_Name/readme.md`) и спроси, какую проверить.

1. Определи предмет по репозиторию или тексту главы и прочитай его профиль.
2. Собери `known.txt` из предыдущих глав: `python3 <папка скилла>/scripts/check_topic.py terms <предыдущие главы> > <временная папка>/known.txt`. Все рабочие файлы клади во временную папку, а не в репозиторий курса.
3. Параллельно запусти агентов `course-topic-writer:reviewer` и `course-topic-writer:student-reader`. Каждому передай полные пути только к файлам из "Получает" его файла роли. Рецензенту скажи, что `sources.md` и плана при проверке нет и проверять нужно без них. Читателю скажи сделать разделы A, B, C и D.
4. Сверь замечания с текстом главы и отбрось ложные. Объедини повторы.
5. Отдай список, сгруппированный так: факты, логика и структура, оформление, язык, понятность для студента, рисунки. В каждом пункте: номер строки, цитата, что не так, предложенная правка. В конце отдельно пункт "Можно добавить" из отчёта Читателя.

Не меняй файл главы, пока пользователь не попросит исправить.
