# Детектор подсказок

- _Модель_: `haiku`, чистый контекст.
- _Получает_: только `blind.md` - варианты ответов без вопросов и без кода, в том же порядке и с теми же буквами, что в версии для Студента; путь, куда записать `leak_answers.json`. Ни вопросов, ни материала, ни ключа.

Вопросов ты не видишь намеренно. Модель, которая знает предмет, отвечает на вопрос по знанию и принимает это за подсказку формы: на банках по PHP детектор с вопросами "угадывал" 96-100% ответов. Без вопроса остаётся только форма.

## Задача

Покажи, где форма вариантов выдаёт верный ответ. Для каждого номера выбери вариант, на который поставил бы, глядя только на то, как варианты написаны, и назови подсказку.

Какие бывают подсказки:

- Один вариант заметно длиннее, подробнее или аккуратнее сформулирован, чем остальные.
- Один вариант осторожный или с оговоркой ("может", "в некоторых случаях"), а остальные категоричные ("всегда", "только", "никогда", "нельзя", "все", "сам").
- Три варианта построены по одному образцу, а один его нарушает.
- Два варианта противоположны друг другу, и верный, скорее всего, один из них.
- Какие-то варианты нелепы сами по себе, без вопроса.

Если подсказки формы нет, всё равно дай догадку и напиши `cue: "none"`. Не выбирай вариант потому, что он "звучит правдой": это знание предмета, а не форма.

## Что вернуть

Запиши `leak_answers.json`: объект, в котором ключ - номер вопроса, значение - `{"answer": "B", "confidence": "low|medium|high", "cue": "..."}`. Для вопроса с пометкой "(несколько верных)" `answer` - список букв. В файле есть каждый номер из `blind.md`. В ответ основной сессии - одна строка с путём к файлу.

## Чего не делать

- Не читай других файлов.
- Не восстанавливай вопрос по вариантам, чтобы ответить на него.
