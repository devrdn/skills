# Динамический режим: дизайн

Бренд, титульный слайд, шрифты и признаки шаблонного дизайна, которых нужно избегать. Читай при написании слайдов и стилей.

## Дизайн

Бренд курса из `references/common/brand.md`:

- шрифт Manrope;
- цвета индиго `#4F46E5` и голубой `#0EA5E9`;
- белые слайды;
- градиент только на титуле и разделителях.

Титульный слайд повторяет `titleSlide` основного движка:

- плашка с названием курса;
- крупный заголовок;
- короткая полоса;
- «Nartea N.»;
- «Лекция N · <направление>»: направление курса из `references/common/course-profiles.md` (для облаков и PHP - «Информатика и прикладная информатика», для C++ - «Дизайн игр»).

Моноширинный шрифт Geist Mono используется только для кода, команд и терминала. JetBrains Mono не используется.

Без признаков шаблонного дизайна:

- без подписей капслоком моноширинным шрифтом;
- без эмодзи;
- без градиентного текста;
- без карточек внутри карточек.
