# Динамический режим: справочник разметки

Атрибуты шагов, классы слайдов, блоков и схем, блоки кода `<xcode>`, значки. Читай при написании `slides.html`.

## Разметка: справочник

**Шаги.**

| Атрибут | Действие |
|---|---|
| `data-in="k"` | элемент появляется на шаге k |
| `data-out="k"` | элемент исчезает на шаге k |
| `data-on="k"` или `data-on="k m"` | класс `on` с шага k; с шага m снова снимается (шаг m уже не входит) |
| `data-cur="k"` или `data-cur="k m n"` | класс `cur` только на перечисленных шагах |

**Слайды.**

| Класс | Назначение |
|---|---|
| `.s-title` | титульный |
| `.s-div` | разделитель раздела, с `data-name` |
| `.s-q` | вопрос |
| `.result` | результат итогового теста |

**Блоки.**

| Класс | Назначение |
|---|---|
| `.grow` | содержимое по центру |
| `.cards.c2`, `.c3`, `.c4` | карточки |
| `.card.def` | определение с плашкой «Определение» (`references/dynamic/content.md`) |
| `.fn`, `.fns.c2` | карточка функции: `.lb`, `.sig`, `p`, `p.ret` |
| `.callout.note`, `.tip`, `.important`, `.warning`, `.caution` | выноска из главы (`references/dynamic/content.md`) |
| `.pc` | плюсы и минусы в две колонки |
| `.card.b`, `.card.r` | цвета «сборка» и «работает» |
| `.after` | строка после блока |
| `.two` | две колонки |
| `.stand` | стенд |
| `.series` | список по шагам |

**Схема.**

| Класс | Назначение |
|---|---|
| `.dg > .area` | поле схемы |
| `.dx` | ряд |
| `.node` | узел; модификаторы `.h`, `.sm`, `.xs`, `.on`, `.bad`, `.down`, `.hot`, `.dim` |
| `.fnode`, `.page`, `.part`, `.slot`, `.chip`, `.bufs` | механики из `references/dynamic/animation.md` |
| `.dx.st` | ряд, где узлы растянуты на высоту веера |
| `.grp` | пунктирная группа; модификаторы `.b`, `.r`, `.x`, `.g`, заголовок `.gl` |
| `.fan > .fr` | веер стрелок |
| `.link` | стрелка (`references/dynamic/animation.md`) |
| `.caps` | подписи к шагам |
| `.pill.ok`, `.pill.no` | метки результата |

Значки: `{{icon:имя}}` → `<i class="ic ic-имя">`. Можно писать и сразу `<i class="ic ic-имя"></i>`: сборщик встраивает иконку, если файл `src/icons/имя.svg` есть.

**Код.** `<xcode lang="php|tpl|bash|js|cpp|text" class="sm|xs" cur="1:2-3;2:5" on="3:4" in="2:6" bad="4">сырой код</xcode>` превращается в `<pre class="code">` с подсветкой синтаксиса. `cur`, `on`, `in` - шаги по строкам («шаг:строки»), `bad` - строки с ошибкой. Внутри строки `⟪текст⟫` выделяет кусок всегда, `⟪k|текст⟫` - с шага k. Код пишется как есть, без `&lt;`: сборщик экранирует сам.

**Свои стили темы** - в `src/topic.css`, он подключается последним.
