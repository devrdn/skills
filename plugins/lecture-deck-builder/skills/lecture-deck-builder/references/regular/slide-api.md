# content.js: формат и типы слайдов

Лекция описывается одним файлом `content.js`, который движок `build_modern.js` превращает в PPTX. Полный рабочий пример - `assets/example_content.js` (лекция 6 курса C++ «Как выполняется программа. Ошибки и отладка»: разминка, разделы, вопросы по ходу лекции, квиз, фильтр студенческой версии). Он собран по действующим правилам и проходит `lint_content.js` без ERROR и WARN, в том числе по бюджету слайдов. Просмотри его, прежде чем писать свой файл: так видно, как типы слайдов сочетаются в настоящей лекции. Картинок из `img/` в скилле нет, поэтому файл показывает формат, но как есть не собирается; содержание примера относится только к C++.

## 1. Каркас файла

```js
const quiz = [ /* вопросы квиза, см. раздел 5 */ ];
const quizQ = quiz.map((q) => ({ type: "predict", only: "q", ...q }));
const quizA = quiz.map((q, i) => ({ type: "predict", only: "a", answerLabel: `Ответ на вопрос ${i + 1}`, ...q }));

const deck = {
  lecture: 6,                       // номер лекции: рисунки получают номера 6.1, 6.2 ...
  title: "ООП в PHP. Часть I",      // метаданные файла
  keywords: ["fmt", "Println"],     // необязательно: дополнительные слова для подсветки в коде
  firstLecture: false,              // true, если вопросов по прошлой теме нет
  slides: [ /* слайды по порядку */ ],
};

if (process.env.STUDENT) { /* фильтр студенческой версии, см. раздел 6 */ }
module.exports = deck;
```

## 2. Разметка внутри текста

Работает во всех текстовых полях, кроме кода:

- `**bold**`: ключевые слова. На каждом слайде выделяй то, что студент должен запомнить, но никогда не целые абзацы.
- `` `mono` ``: имена функций, типов, операторов, ключевых слов, команд и файлов в обычном тексте.
- `*italic*`: редко. Одиночная `*` в заголовке слайда ломает макет (остаток заголовка становится курсивом), поэтому звёздочки в заголовках не используй никогда.

Пункты списка (`items`) - это строка или `{ lead: "Термин.", text: "пояснение" }`; `lead` показывается жирным.

## 3. Общие поля

Есть у большинства типов:

| Поле | Назначение |
|---|---|
| `title` | Заголовок слайда (правила заголовков: `references/common/content-rules.md`, §6) |
| `intro` | Вводная строка под заголовком, перед основным блоком |
| `after` | Одно предложение после основного блока: вывод слайда |
| `source` | Мелкая серая строка внизу: «PHP Documentation (2026). Exceptions.» |
| `fs` | Размер шрифта основного блока, заданный вручную. Нужен редко: движок подбирает размеры сам |
| `setPart` | Текст колонтитула начиная с этого слайда («Повторение», «Итоги») |
| `quiz: true` | Слайд квиза: удаляется из студенческой версии |
| `lineNumbers: false` | Отключает номера строк в блоках кода этого слайда (для вывода программы, диалогов в консоли) |

Колонтитул «NN. Название раздела» ставится автоматически после каждого слайда `section`.

## 4. Типы слайдов

### title

```js
{ type: "title", course: "Веб-разработка", title: "Объектно-ориентированное программирование в PHP. Часть I",
  meta: "Лекция 6  ·  Информатика и прикладная информатика" }
```

`course` и `meta` для каждого курса: см. `references/common/course-profiles.md`.

`author` по умолчанию «Nartea N.». `course` показывается плашкой над заголовком.

### section

```js
{ type: "section", part: 2, title: "Исключения" }
```

Градиентный разделитель с номером «02». Задаёт колонтитул следующих слайдов.

### bullets

```js
{ type: "bullets", title: "План лекции", numbered: true, gap: 2, items: ["...", "..."],
  intro: "...", after: "...", start: 0 }
```

`numbered` - нумерованный список; `start` - сдвиг нумерации; `gap` - расстояние между пунктами в pt (по умолчанию 9, допускается `0`).

### def

```js
{ type: "def", title: "Понятие исключения", term: "Исключение (exception)", definition: "объект, описывающий ...",
  term2: "...", definition2: "...", items: ["..."], intro: "...", after: "...", source: "..." }
```

Карточка определения: термин цветом бренда, затем дефис и определение со строчной буквы. `numbered: true` нумерует пункты (для упорядоченных частей). Второе определение (`term2`) получает вторую карточку. Это единственный способ ввести новый термин. Не перегружай слайд: карточка и либо до трёх коротких пунктов, либо одно предложение `after`, но не то и другое вместе.

### code

```js
{ type: "code", title: "Объявление конструктора", lang: "php", code: "class Product\n{\n...}",
  label: "PHP 8.4", code2: "program output", lang2: "text", label2: "вывод",   // плашки: примерно до 14 символов
  items: ["..."], columns: [["item", "item"], ["item"]], intro: "...", after: "..." }
```

Тёмный блок кода с номерами строк (номера добавляются автоматически для любого `lang`, кроме `text`, если в коде от двух строк). Размер шрифта подбирается автоматически от 14 до 10 pt по ширине и высоте. `code2` - второй блок под первым (например, вывод программы); без `lang2` он показывается как `text`. `columns` - две колонки пунктов под кодом, только в виде массива массивов.

### codepair

```js
{ type: "codepair", title: "Способы сообщить об ошибке", lang: "php",
  left:  { label: "Возврат false", code: "...", text: "caption under the code" },
  right: { label: "Остановка скрипта", code: "...", text: "..." },
  after: "shared conclusion, full width", textFs: 14, capFs: 14 }
```

Две колонки, в каждой код или текст. Главный инструмент для пар «проблема / решение», «до / после» и «объявление / использование». Колонка без `code` становится светлой карточкой с `text` и/или `items` (например, код слева, пояснение справа). В колонку помещается около 44 символов кода при 10 pt: длинные строки переноси вручную или сокращай пример.

### table

```js
{ type: "table", title: "Модификаторы видимости", header: ["Модификатор", "Где доступен"],
  rows: [["`public`", "Везде"], ["`private`", "Только в классе"]], colW: [2, 5], dense: true, after: "..." }
```

`colW` - относительные ширины колонок. `dense` - плотные строки. Первая колонка набирается жирным (`firstBold: false` это отключает).

### tablebuild

```js
{ type: "tablebuild", title: "Сравнение объектов: == и ===", intro: "`$a = ...; $b = clone $a;`",
  ask: "Что дадут сравнения?", header: [...], rows: [...], reveal: [1, 2], dense: true, after: "..." }
```

Таблица с угадыванием для версии преподавателя: на первой странице колонки из `reveal` показаны как «?», на второй они заполнены. `stepwise: true` вместо этого открывает по одной строке на страницу (число строк + 1 страница; используй редко, это раздувает презентацию). В бюджете считается одним слайдом; в студенческой версии превращается в обычную заполненную таблицу.

`ask` - приглашение угадать («Угадываем построчно.»): показывается акцентным цветом под `intro` и удаляется из студенческой версии. В `intro` оставляй только условия (сценарий, код, ARN): они нужны и студентам. `source` у этого типа не показывается.

### compare

```js
{ type: "compare", title: "Обычные и постоянные покупатели", intro: "...",
  left: { label: "Обычный", items: ["..."] }, right: { label: "Постоянный", items: ["..."] }, after: "..." }
```

Две светлые карточки с плашками. Для сравнения понятий без кода.

### alert

```js
{ type: "alert", kind: "WARNING", title: "Пустой блок catch", text: "...", after: "...", items: ["..."] }
```

`kind`: `NOTE`, `IMPORTANT`, `WARNING`, `TIP`. Выделяй жирным ту часть, которая содержит рекомендацию.

### image

```js
{ type: "image", title: "Модели хранения данных", image: "img/l6_storage_models.png",
  caption: "Модели хранения данных", source: "...", intro: "...", after: "...", maxw: 7.5 }
```

Рисунок в светлой карточке с подписью «Рис. 6.N.» (номер ставится автоматически по порядку появления в презентации; `num: "3.5"` задаёт номер вручную, если он должен совпадать с главой). `after` стоит под подписью, шрифтом 14 pt, а рисунок уменьшается, чтобы освободить место. Область рисунка - примерно 8,2 × 3,4 дюйма, поэтому высокую схему ограничивает высота: убери `intro`/`after`, чтобы дать ей больше всего места, а `maxw` задавай, только чтобы сузить широкий рисунок. Файл положи в `img/` рабочей папки. Только рисунки из источника. SVG сначала переведи в PNG (cairosvg, масштаб 2,5-3, белый фон).

### predict

Вопрос аудитории. Он всегда занимает **две страницы**, и в версии преподавателя, и в студенческой: страница вопроса (заголовок, вопрос, код), затем страница ответа. Страница ответа называется «Ответ: ...» (движок заменяет начальное «Вопрос:»; `answerTitle` задаёт заголовок вручную). На ней повторяется код, если он ещё помещается при 10,5 pt или крупнее, а затем идут карточка ответа и `after`.

```js
{ type: "predict", title: "Вопрос: выполнение после throw", noPill: true,
  question: "Что увидит пользователь?", lang: "php", code: "...",
  answer: "**Короткий жирный ответ.** Пояснение в одно-два предложения.",
  answerItems: ["...", "..."], answerNumbered: true, after: "..." }
```

Вне квиза всегда ставь `noPill: true` и заголовок «Вопрос: тема». `showCodeInAnswer: false` никогда не повторяет код на странице ответа, `true` повторяет его всегда (даже мелким шрифтом). Старые поля `split`, `side` и `stacked` игнорируются. Варианты `options` (A-D) - для квиза, в котором вопросы и ответы всегда идут отдельными страницами через `only: "q"` / `only: "a"`. Код квиза пишется в `code` (показывается шрифтом 11 pt или крупнее, с номерами строк); если при таком размере он не помещается, слайд выходит за край, и движок об этом сообщает: сократи код или варианты.

### statement

```js
{ type: "statement", label: "Время вышло", text: "Сдаём листки с ответами. Теперь разбираем правильные ответы." }
```

Градиентный слайд с одним крупным предложением. В лекции используй редко: для ключевого утверждения или для паузы в квизе.

### handson

```js
{ type: "handson", label: "Hands-on 6.1", title: "Создание бакета" }                 // Cloud: только плашка и заголовок, крупно
{ type: "handson", label: "Практика 6.1", title: "...", items: ["..."], note: "Парами, 20 минут" }
```

### refs

```js
{ type: "refs", title: "Библиография", fs: 10, items: ["Author (year). *Title*. Available at: URL"] }
```

Около 9 источников с длинными URL помещаются на один слайд при `fs: 10`. Более длинный список раздели на «Библиография (1 из 2)» и «Библиография (2 из 2)», а на втором слайде поставь `start: 12`, чтобы нумерация продолжилась.

## 5. Квиз

Командный квиз: 8 вопросов, последний стоит 2 балла. Порядок: разделитель раздела, правила, все вопросы, «Время вышло», все ответы.

```js
const quiz = [
  { voteLabel: "Вопрос 1 из 8", title: "Обращение к свойству", question: "Что означает `$product->$name`?",
    options: ["...", "...", "...", "..."],
    answer: "**C.** Пояснение." },            // буква в начале answer выделяет верный вариант
  { voteLabel: "Вопрос 3 из 8", title: "Присваивание объекта", question: "Что выведет код?", lang: "php",
    code: "$a = new Product('Ноутбук', 14999);\n$b = $a;\n$b->price = 9999;\necho $a->price;",   // код строками, а не внутри предложения
    options: ["14999", "9999", "Ошибку", "0"], answer: "**B. 9999.** Пояснение." },
];
// в slides:
{ type: "section", part: 9, title: "Командный квиз", quiz: true },
{ type: "bullets", title: "Правила квиза", quiz: true, items: [
  "Команды по 4-5 человек, у каждой **название** и листок для ответов.",
  "На вопрос **30 секунд**, ответ пишем буквой.",
  "Верный ответ - **1 балл**, последний вопрос - **2 балла**.",
  "Сначала все 8 вопросов, затем **сдаём листки** и вместе разбираем ответы." ] },
...quizQ.map((q) => ({ ...q, quiz: true })),
{ type: "statement", quiz: true, label: "Время вышло", text: "Сдаём листки с ответами. Теперь разбираем правильные ответы." },
...quizA.map((q) => ({ ...q, quiz: true })),
```

Двуязычный квиз (по запросу): поля `questionEn`, `optionsEn`, `answerEn`; `voteLabel: "Вопрос 1 из 8 · Question 1 of 8"`, `answerLabel: "Ответ на вопрос 1 · Answer 1"`. На странице ответа английский текст показывается только у верного варианта.

## 6. Студенческая версия

В конце content.js стоит фильтр студенческой версии (она собирается с `STUDENT=1`):

```js
if (process.env.STUDENT) {
  deck.slides = deck.slides
    .filter((sp) => !sp.quiz)
    .map((sp) => {
      if (sp.type === "tablebuild") { const { ask, reveal, ...rest } = sp; return { ...rest, type: "table" }; }
      if (sp.title === "План лекции") return { ...sp, items: sp.items.filter((i) => i !== "Командный квиз.") };
      return sp;
    });
}
```

## 7. Подсветка кода

`lang`: `php`, `cpp`, `js`, `bash`, `json`, `pseudo` (псевдокод: с номерами строк и общей подсветкой), `text` (вывод программы, деревья, диалоги в консоли: без номеров и без подсветки). Подсвечиваются комментарии (`//`, `#`, `/* */`), строки, `$variables`, числа и ключевые слова из встроенного списка. Для других языков (Python, Go, SQL, YAML) выбери ближайший (`bash` для комментариев `#`, `cpp` для `//`) и добавь слова языка в `deck.keywords`. Деревья и вывод программы: `lang: "text"`.

## 8. Ограничения и подводные камни

- Область содержимого заканчивается на 5,02 дюйма; всё, что ниже, наезжает на колонтитул. Движок печатает `WARN [слайд N] переполнение (type): низ X > 5.02`; номер слайда совпадает с номером страницы PDF.
- Строка `source` стоит внизу слайда. Если содержимое доходит до неё, движок печатает `наложение на строку источника`: сократи текст или убери `source`.
- Основной текст - 16 pt, таблицы - 14 pt. В `bullets` и `def` движок сам уменьшает пункты до 14 pt, когда не хватает места, но ниже никогда не опускается. Из-за этого сокращение текста иногда «ничего не меняет», пока не уменьшится число строк. Когда содержимое не помещается, сначала сокращай, потом дели слайд или переноси часть в `codepair`/`columns`. Уменьшить `fs` блока кода вручную до 9 pt - крайняя мера.
- Строка кода длиннее примерно 80 символов не помещается во всю ширину при 10 pt, а в колонке `codepair` - длиннее 40 символов (номера строк занимают 3-4 символа).
- `columns: true` и `code2` без `lang2` - частые ошибки; `lint_content.js` их ловит.
