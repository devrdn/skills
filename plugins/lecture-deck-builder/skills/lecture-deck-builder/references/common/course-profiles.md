# Профили курсов

Чем отличаются курсы (титульный слайд, язык кода, проверка кода, префикс имени файла). Читай, когда курс определён по источнику, до титульного слайда и до сдачи файлов.

Определи курс по источнику (репозиторий, название главы). Для неизвестного курса действуют общие правила.

Титульный слайд по курсам (плашка `course` / `meta`):

| Курс | `course` | `meta` |
|---|---|---|
| Cloud Computing | «Cloud Computing» | «Лекция N · Информатика и прикладная информатика» |
| Веб-разработка (PHP) | «Веб-разработка» | «Лекция N · Информатика и прикладная информатика» |
| Программирование (C++) | «Программирование» | «Лекция N · Дизайн игр» |
| Новый курс | название курса из источника | «Лекция N · <специальность из источника>» |

- **Cloud Computing (AWS).** Слайды hands-on пустые. Когда сервис вводится впервые, в источнике обычно есть «карточка сервиса» (категория, что сервис делает, зачем он нужен, модель IaaS/PaaS/SaaS, год запуска): перенеси её таблицей. Архитектурные схемы только из источника.
- **Веб-разработка (PHP).** `lang: "php"`. Если установлен `php`, проверь им код. Версия PHP - как указано в главе (например, 8.4).
- **Программирование (C++).** `lang: "cpp"`. Если установлен `g++`, проверь им код. Аудитория - студенты направления «Дизайн игр», поэтому формулировки держи простыми. Квиз может быть двуязычным, если автор попросит.
- **Новый курс.** Название курса для плашки на титульном слайде возьми из источника; всё остальное - по общим правилам.

Префикс имени файла: `Cloud`, `Веб`, `Программирование` или короткое название нового курса.
