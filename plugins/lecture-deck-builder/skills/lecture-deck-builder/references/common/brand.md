# Бренд

У всех лекций автора один визуальный стиль, чтобы курс выглядел цельным. Стиль встроен в `engine/build_modern.js`, поэтому не обходи его: не меняй в движке цвета, шрифты, размеры и сетку и не строй слайды в обход движка. Если для одной лекции просят «другой дизайн», сначала спроси, не нужно ли сменить бренд всего курса.

## Палитра

| Роль | Цвет | Где |
|---|---|---|
| Цвет заголовков | `#0B0B12` | Заголовки слайдов |
| Основной текст | `#3A3F4A` | Абзацы, пункты списков |
| Акцент 1 (индиго) | `#4F46E5` | Термины, плашки, номер страницы, шапки таблиц |
| Акцент 2 (голубой) | `#0EA5E9` | Второй термин, вторая колонка, плашки вопросов |
| Подложки | `#F4F5F8`, `#F7F8FA` | Карточки определений, ответов и рисунков |
| Приглушённый | `#9AA0AA` | Колонтитул, источники |
| Фон кода | `#0F1626` | Блоки кода (тёмная тема подсветки) |
| Предупреждение | `#FFF6EC` / `#F59E0B` | WARNING |
| Совет | `#EEF8FD` | TIP |

Градиент от индиго к голубому (`img/grad_full.png`) используется только на разделителях разделов, слайдах-утверждениях, слайдах hands-on и на «Время вышло». Мягкий градиент (`img/grad_soft.png`) - только на титульном слайде. Содержательные слайды белые.

## Типографика

- Manrope (Regular/Bold) для всего текста; IBM Plex Mono для кода и моноширинных вставок в тексте.
- Размеры фиксированы: заголовок 25 pt, основной текст 16 pt, таблицы 14 pt, подписи 13 pt, колонтитул 9,5-10,5 pt, разделитель раздела 40 pt, номер раздела 62 pt. Hands-on: плашка 15 pt, заголовок 44 pt (38 pt, если на слайде есть пункты).
- Код: перед каждой строкой номер строки тусклым серо-синим цветом (`#4F5B7A`).
- Иерархия задаётся только размером и насыщенностью шрифта, без дополнительных шрифтов и цветов.

## Сетка

- 16:9, 10 × 5,625 дюйма. Поля 0,66 дюйма, ширина содержимого 8,68 дюйма.
- Колонтитул: слева «NN. Раздел», справа номер страницы цветом индиго. Слово «Часть» не пишется никогда.
- Содержимое заканчивается на 5,02 дюйма; колонтитул начинается на 5,27 дюйма.

## Анимация

`post.py` добавляет переход «растворение» (fade) каждому слайду, а основная часть содержательных слайдов появляется по щелчку. Вопросы в лекции занимают две страницы (вопрос, затем ответ), и на каждой из них основная часть тоже появляется по щелчку. На титульном слайде, разделителях, утверждениях и hands-on анимации нет. Другие анимации не добавляй.

## Чего не делать

- Иконки, клипарт, стоковые фото, декоративные линии под заголовками.
- Новые цвета, чтобы «оживить» слайд.
- Рисунки не из источника, сгенерированные картинки.
- Уменьшение текста, чтобы он поместился: вместо этого сократи слайд или раздели его.
