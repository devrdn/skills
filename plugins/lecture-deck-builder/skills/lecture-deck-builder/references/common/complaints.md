# Жалобы автора, из которых выросли правила

Зачем нужно каждое правило скилла: на какую жалобу автора оно отвечает и чем ловится. Читай при правке самого скилла или когда непонятно, зачем правило.

| Жалоба | Правило | Чем ловится |
|---|---|---|
| Ответ виден вместе с вопросом | `references/common/questions.md`: вопрос и ответ на разных страницах | обычный движок разделяет `predict`; в динамическом режиме ответ открывается по клику |
| Слайды не по порядку, не связаны | `references/common/content-rules.md`, §5 | рецензент плана, пометки `story.js`, студент-читатель |
| «Поэтому», «Однако», «Начнём с» на слайдах | `references/common/content-rules.md`, §5: слайд сообщает факты, а не рассказывает | `lint_content.js`, языковой редактор |
| Стены текста, неуклюжий русский | `references/common/content-rules.md`, §7 | `lint_content.js`, языковой редактор, этап D |
| Неверные ответы в вопросах по коду | `references/common/content-rules.md`, §1 | проверка кода |
| Версия для пары читается как стена пунктов | `references/regular/pair-deck.md`: карточки, шаги, сравнения, числа | WARN сборки, проверка вёрстки |
| Заголовок ничего не говорит о слайде | SKILL.md, шаг 2, проверка связности | рецензент плана |
| Анимация функции до того, как сказано, что она делает | `references/dynamic/content.md` и `references/dynamic/animation.md`: сначала карточка функции | рецензент плана, проверка анимаций |
| Анимация как шум: точки там, где ничего не движется, элементы раньше своего шага | `references/dynamic/animation.md`: у движения есть смысл | проверка анимаций, скриншоты каждого шага |
| Стрелки мимо узлов или заходят на рамку, текст за рамкой узла | `references/dynamic/animation.md`, «Геометрия» | `check_fit.js` |
| Определения выглядят как любые карточки или разного цвета | `references/dynamic/content.md`: один вид и один цвет определений | скриншоты |
| TIP, NOTE, WARNING главы потеряны или оформлены карточкой ошибки | `references/dynamic/content.md`: выноски своего цвета, 2-3 на лекцию | рецензент по фактам, скриншоты |
| Собственные функции главы показаны как единственный способ | `references/dynamic/content.md`: «Реализация метода N» | рецензент плана |
